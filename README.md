# Genesis Aluglass — Architectural Editorial

Five-page corporate website built with Next.js App Router and React.

## Pages
- `/` — Home
- `/services` — Aluminium and glass services
- `/projects` — Actual swing-door installation and clearly labelled AI-generated architectural references
- `/about` — Company introduction and working approach
- `/contact` — WhatsApp enquiry form

## Run locally
1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Deploy
Connect the project to a Vercel project using the Next.js framework preset and deploy from the project root.

## Brand and content notes
- The supplied Genesis Aluglass logo and original light-blue/charcoal brand identity are retained.
- The swing-door installation photograph is supplied project photography.
- Other architectural imagery is AI-generated and labelled as illustrative, not as completed Genesis projects.
- WhatsApp enquiries open a pre-filled message to `+60 14-812 2623`; no message is sent until the visitor presses Send in WhatsApp.
- Service descriptions are intentionally general. Confirm technical specifications, warranties, operating hours, address, and any additional contact details before public launch.
